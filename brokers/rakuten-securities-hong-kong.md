**乐天证券香港（Rakuten Securities Hong Kong Limited）** 前身为福汇亚洲（FXCM Asia Limited），自 2003 年起扎根香港外汇市场，2015 年被日本最大线上券商之一——乐天证券株式会社（母公司为日本上市巨头乐天集团 `TOKYO: 4755`）全资收购并更名。公司持有香港证券及期货事务监察委员会（SFC）第 3 类杠杆式外汇交易牌照（中央编号 **`AIM232`**），客户资金独立存放在中国银行（香港）与恒生银行的隔离账户中。

与主打高杠杆的离岸券商不同，乐天证券香港严格遵循香港证监会监管框架：最大杠杆为 **1:20**（5% 初始保证金），专注 **46 对外汇货币对**，凭借母公司雄厚的流动性提供 **0 佣金、低至 0.2 点的固定点差**，并支持香港金管局 **eDDA 快捷存款** 与 **转数快（FPS）**，适合持有香港银行账户、看重资金安全与低点差成本的稳健型外汇交易员。

## 自研交易终端生态：MARKETSPEED FX、iSPEED FX 与网页端

乐天证券香港的外汇业务完全采用日本乐天证券自研的 **乐天 FX（Rakuten FX）** 交易系统，**不提供 MT4/MT5 或 EA 自动化交易接口**：

* **MARKETSPEED FX（桌面端）**：支持 7 种可定制订单类型（含一击交易 Streaming / AS SPEED、OCO、IFO 等）、9 款图表与 44 种技术指标，支持直接从图表下单与管理仓位；
* **iSPEED FX（移动端 iOS / Android）**：支持单屏显示 4 个图表、图表一击下单与自定义价格提醒，界面风格延续日系高频看盘习惯；
* **乐天 FX Web（网页端）**：兼容 Windows 与 macOS 浏览器（Chrome、Safari、Edge、Firefox），免下载安装即可调用 30+ 技术指标；
* **黄金白银独立平台提示**：若需交易现货黄金（XAUUSD）或白银（XAGUSD），需另行在姊妹公司 **乐天证券金业香港有限公司（`bullion.rakuten.com.hk`）** 开户并使用其 **乐天 MT4 平台**，两家公司账户与监管体系相互独立。

## 固定点差、按量点差平通阶与 1:20 保证金规则实测

根据 `sec.rakuten.com.hk/zh-hans/trading-platform/rakuten-fx/rate-table` 与 `/trading-rules` 披露，乐天证券香港提供美元或港元结算账户，最小下单 **1,000 单位（0.01 手）**，单笔最大 **5,000,000 单位（50 手）**，全系 **0 交易佣金**：

* **极低固定点差与“按量点差平通阶”**：平台对 10 款主流货币对（USDJPY、EURUSD、AUDUSD、GBPUSD、NZDUSD、EURJPY、USDCAD、AUDJPY、GBPJPY、USDCHF）推出按单笔交易量阶梯收窄点差机制，实盘报价中 **USDJPY 低至 0.2 点**、**EURUSD 与 AUDUSD 低至 0.3 点**、**EURJPY 低至 0.5 点**、**GBPUSD 与 GBPJPY 低至 0.9 点**（USDHKD 约 2.8 点、USDCNH 约 7.0 点）；
* **1:20 法定杠杆与三档保证金线**：除 5 种高波动货币对（USDNOK、EURNOK、USDSEK、EURSEK、TRYJPY）外，常规货币对初始保证金为开仓净值的 **5%（即 1:20 杠杆）**；当保证金状况低于 **100%（5%）** 时禁止建立新仓位，低于 **60%（3% 维持保证金）** 时发出追加保证金提示，低于 **40%（2% 自动结算保证金）** 时系统将强制平仓。

## 监管牌照核查：香港证监会 SFC AIM232 与资金隔离

在华语区外汇市场中，持有香港证监会（SFC）第 3 类牌照的零售外汇商屈指可数，乐天证券香港的合规透明度处于第一梯队：

* **香港证监会 SFC 第 3 类牌照（`AIM232`）**：**`乐天证券香港有限公司`（Rakuten Securities Hong Kong Limited）** 受香港证监会监管，中央编号 **`AIM232`**，获准从事第 3 类受规管活动（杠杆式外汇交易），可在 [香港证监会持牌人及注册机构公众纪录册](https://apps.sfc.hk/publicregWeb/corp/AIM232/details) 公开查验；
* **本地持牌银行独立托管**：所有客户资金均独立存放在乐天证券香港于 **中国银行（香港）** 与 **恒生银行** 开立的客户隔离账户内，与公司自有运营资金严格分离；
* **开户身份与银行账户要求**：香港居民及合资格非永久性香港居民（含中国内地居民）均可申请，但必须提供政府签发身份证、护照（非永久性香港居民适用）以及**本人名下香港持牌银行账户证明**（如银行结单或提款卡），不接受第三方存款或信用卡入金。

* **四种入金通道（均免平台入金费）**：
  * **eDDA 快捷存款（仅限港元）**：绑定本人香港银行账户授权后，最快 **5 分钟内** 到账，支持 24 小时提交；
  * **转数快 FPS（仅限港元）**：转账至 FPS 识别码 `65472442` 并电邮截图至 `admin@sec.rakuten.com.hk`，约 **1 个工作日** 入账；
  * **香港银行转账（HKD / USD）**：支持中银香港与恒生银行本地转账或 SWIFT 电汇，约 **1–4 个工作日**；
  * **电子支票 / 支票（HKD / USD）**：约 **1–2 个工作日**；
* **出金收费与汇率规则**：香港支票出金 **免费**；香港本地银行转账/电汇收取 **50 港元或 7 美元**；国际电汇收取 **150 港元或 20 美元**；若账户以美元结算而存入港元，按 **7.85 港元兑 1 美元** 兑换（港元账户存入美元按 **1 美元兑 7.75 港元** 兑换）；

## 开户通提醒：实盘客观痛点与注意事项

结合香港证监会监管规则与乐天证券香港实盘条款，开户通提醒交易员重点留意以下四点：

1. **必须拥有本人名下香港持牌银行账户**：
   * 乐天证券香港不接受中国内地银行卡直连、银联、信用卡或 USDT 入金，网上开户必须从本人香港银行账户转入首笔 **10,000 港元**（无香港银行卡的内地交易员无法完成线上入金）；
2. **1:20 杠杆与 40% 强平线对资金利用率要求较高**：
   * 受香港 SFC 法定 5% 初始保证金限制，交易 1 标准手欧美约需 5,500 美元保证金，且净值跌破开仓净值的 2%（保证金状况 40%）即触发强平，不适合小资金重仓短线；
3. **不支持 MT4/MT5 与 EA，且不含黄金/股指**：
   * 乐天证券香港仅提供自研 MARKETSPEED FX / iSPEED FX / 网页端与 46 对外汇货币对；若需交易黄金白银或使用 MT4，需另行在姊妹公司乐天证券金业开户（该金业实体不受 SFC 第 3 类牌照监管）；
4. **留意本地与国际电汇出金手续费**：
   * 仅香港支票出金免费，本地银行转账出金每笔收 50 港元（或 7 美元），国际电汇每笔收 150 港元（或 20 美元），小额频繁出金成本偏高。

<div class="rank-math-answer "><p>是正规持牌机构。乐天证券香港有限公司是日本乐天集团（TOKYO: 4755）旗下乐天证券株式会社的全资子公司，持有香港证监会（SFC）第 3 类杠杆式外汇交易牌照（中央编号 AIM232），客户资金独立存放在中银香港与恒生银行。</p></div>
</div>
<div id="faq-question-2" class="rank-math-list-item">
<h3 class="rank-math-question ">中国内地居民可以开立乐天证券香港账户吗？需要什么条件？</h3>
<div class="rank-math-answer "><p>合资格的非永久性香港居民（含内地居民）可申请开户，但必须提供政府签发身份证、护照以及本人名下香港持牌银行账户证明；若通过网上开户，还须从本人香港银行账户转入首笔不少于 10,000 港元的资金。</p></div>
</div>
<div id="faq-question-3" class="rank-math-list-item">
<h3 class="rank-math-question ">乐天证券香港的最大杠杆和爆仓比例是多少？</h3>
<div class="rank-math-answer "><p>遵循香港证监会法定要求，最大杠杆为 1:20（初始保证金 5%）。当保证金状况低于 100%（5%）时无法开新仓，低于 60%（3% 维持保证金）发出追保提示，低于 40%（2% 自动结算保证金）将触发强制平仓。</p></div>
</div>
<div id="faq-question-4" class="rank-math-list-item">
<h3 class="rank-math-question ">乐天证券香港支持 MT4 或交易黄金吗？</h3>
<div class="rank-math-answer "><p>乐天证券香港（sec.rakuten.com.hk）仅提供 46 对外汇货币对，使用自研 MARKETSPEED FX、iSPEED FX 与网页端，不支持 MT4/MT5。黄金与白银交易由姊妹公司乐天证券金业香港有限公司（bullion.rakuten.com.hk）通过乐天 MT4 独立提供，不受 SFC 第 3 类牌照监管。</p></div>
</div>
<div id="faq-question-5" class="rank-math-list-item">

<div class="rank-math-answer "><p>平台实行 0 佣金固定点差，USDJPY 低至 0.2 点、EURUSD 与 AUDUSD 低至 0.3 点。支持 eDDA 快捷存款（港元最快 5 分钟到账）、转数快 FPS 与香港银行转账，入金免费；出金方面香港支票免费，本地银行转账收 50 港元/7 美元，国际电汇收 150 港元/20 美元。</p></div>
</div>
