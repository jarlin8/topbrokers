创立于 2006 年的 **Advanced Markets（`advancedmarkets.com`）** 是一家专注于机构外汇与多资产流动性的老牌 **Prime-of-Prime（PoP）** 提供商，由现任 CEO Anthony Brocco 创立，背后股东包括 BGC 集团（GFI Group）、麦格理集团（Macquarie Group）以及 2021 年 5 月入股的 FXFY LLC（Forexify）与 Corbel Capital Partners。其英国运营主体 `Advanced Markets (UK) Ltd` 持有**英国金融行为监管局（FCA，FRN: 777739）**牌照，办公地点位于伦敦（52-56 Bermondsey Street, London SE1 3UD）。

与面向个人开户的零售外汇券商完全不同，Advanced Markets 走的是**纯 B2B 机构直通路线**：通过瑞银（UBS AG）与渣打银行（Standard Chartered Bank）两大 Tier-1 主经纪商，为中小型券商、对冲基金、资管机构与专业交易团队提供 **FIX API 4.4**、**MT4/MT5 桥接** 与 **Fortex 6** 流动性接入（目标执行延迟低于 10 毫秒）。**普通零售散户无法直接在英国 FCA 实体开户**，机构与专业账户通常需要 **20,000 至 50,000 美元以上** 的资金门槛与完整的企业尽调。

## 机构级 Prime-of-Prime 流动性网络与技术接入矩阵

作为连接顶级银行与中小型经纪商/基金的桥梁，Advanced Markets 的核心壁垒在于其主经纪商信用授信与低延迟技术生态：

* **Tier-1 主经纪商与 20+ 流动性池**：由 **瑞银（UBS AG）** 与 **渣打银行（Standard Chartered Bank）** 担任主经纪商（Prime Brokers），并可按机构客户需求在 **麦格理银行（Macquarie Bank）** 开设独立隔离托管账户；流动性报价聚合自摩根大通（JP Morgan）、XTX Markets、法国巴黎银行（BNP Paribas）、德意志银行（Deutsche Bank）等 20 余家顶级银行与非银做市商；
* **FOX 全额成交与无 Last-Look 机制**：采用自研 Full Order Execution（FOX）与纯 STP 直通模式，官方披露目标订单执行延迟低于 **10 毫秒**、拒单率低于 **2%**，消除做市商人工干预与 Last-Look 拒单；
* **FIX API 4.4 与主流桥接全兼容**：支持通过 **FIX API 4.4** 直连 FastMatch、Integral、Currenex 等机构枢纽，并深度集成 **PrimeXM XCore**、**Fortex**、**oneZero**、**Lucera LUMEMarkets**、**YourBorse**、**Tools for Brokers** 与 **Othello Bridge**（满足条件的流动性客户可获第三方 MT4/MT5 桥接费用减免）；GUI 终端支持 **Fortex 6**、**MT4** 与 **MT5**。

## 机构账户模式、保证金要求与合约规格拆解

Advanced Markets 根据客户资金体量与技术架构提供 **Prime Broker 直连**、**Prime-of-Prime（PoP）机构账户** 与 **共享服务器 MT4/MT5 机构端** 三种合作模式，服务器时区采用美东时间（冬令时 EST / 夏令时 EDT，每日 16:55–17:10 ET 系统重置）：

* **外汇保证金与杠杆**：29 个主要货币对最低保证金要求为 **1%（即 1:100 杠杆）**，最小交易手数 **0.01 手**、单笔上限 200 手；交叉盘与离岸人民币（`USDCNH` / `EURCNH`）保证金为 **2%（1:50）**；墨西哥比索与泰铢为 **4%（1:25）**；土耳其里拉与以色列谢克尔为 **10%（1:10）**；
* **贵金属、股指、大宗商品与加密货币 CFD**：现货黄金（`XAUUSD` / `XAUEUR`）与白银（`XAGUSD`）支持 0.01–100 手；现金股指与原油 CFD（如 `US30`、`NAS100`、`GER40`、`HK50`、`USOIL`、`UKOIL`）按合约名义价值计收低额佣金（官网示例 1 手 DAX 合约佣金约 0.15 美元）；另提供黄金/原油/股指期货合约及 BTC、ETH、BCH、LTC、XLM 加密货币 CFD。

| 核心对比项 | Prime Broker 直连模式 | Prime-of-Prime (PoP) 机构账户 | 共享服务器 MT4/MT5 机构端 |
| :--- | :--- | :--- | :--- |
| **适用对象** | 拥有自有银行 PB 授信的大型机构 | 中小型券商、对冲基金、资管团队 | 专业交易团队与合格专业客户 |
| **接入方式** | FIX API 4.4 / 专线交叉连接 | FIX API / PrimeXM / oneZero / Fortex | MT4 / MT5 / Fortex 6 |
| **资金门槛参考** | 需自有 Tier-1 银行 PB 授信 | 通常 **50,000 美元起** | 通常 **20,000 美元起** |
| **点差与佣金** | 银行间原始裸点差（0.0 点起） | 原始裸点差 + 阶梯成交量佣金 | 原始点差 + 机构协议佣金 |
| **主要货币对杠杆** | 按 PB 授信协议 | 最高 **1:100**（1% 保证金） | 最高 **1:100**（1% 保证金） |

## 监管牌照核查与纯 B2B 准入边界

围绕 Advanced Markets 的监管实体与牌照归属，早期中文资料存在不少混淆（例如误写持有法国 AMF 或瓦努阿图 VFSC 牌照），开户前务必以官网法律披露为准：

### 英国 FCA 777739、澳洲 ASIC 444649 与百慕大实体拆解

* **英国 FCA（`FRN: 777739`）**：`Advanced Markets (UK) Ltd`（英国公司号 `10671764`）于 2018 年 4 月 10 日获英国 FCA 授权为 Matched Principal 经纪商，可在 [英国 FCA 官方登记库（FRN 777739）](https://register.fca.org.uk/s/firm?id=001b000003mzFThAAM) 查验。官网页脚明确声明：**该实体仅向符合 FCA 与 MiFID 规则的专业客户（Professional）或合格对手方（Eligible Counterparty）提供服务**；
* **澳大利亚 ASIC（`AFSL 444649`）**：2013 年退出美国 NFA 后，集团通过开曼实体 `Advanced Markets Ltd` 取得澳洲 ASIC 牌照（`AFSL 444649`），面向批发与机构客户（2015 年 ASIC 曾发布公告要求其明确非澳洲客户不受 ASIC 保护）；
* **美国控股主体与百慕大实体**：`Advanced Markets LLC`（美国北卡罗来纳州注册号 `L08000063350`）仅作为网站所有方与集团控股实体，不在全球招揽或开展受监管业务；`Advanced Markets (Bermuda) Ltd`（注册号 `56562`）为百慕大豁免公司注册实体，不持有 BMA 投资业务牌照；**此外，Advanced Markets 并不持有法国 AMF 或瓦努阿图 VFSC 牌照**。

### 严禁零售散户开户与冒名黑平台警示

Advanced Markets 官网 FAQ 明确回答：“真正的 Prime-of-Prime 仅做纯 B2B 业务，不直接服务零售散户。”此外，公司曾专门发布官方声明，否认与面向散户的离岸平台 **Cooper Markets** 存在任何关联。市面上任何声称“Advanced Markets 零售开户”或“低门槛跟单”的渠道均需高度警惕。

## 机构资金门槛、出入金与券商间划转实测

由于定位纯 B2B 机构流动性商，Advanced Markets 的资金存取流程与零售平台截然不同：

* **资金门槛与企业尽调**：机构与专业账户通常要求 **20,000 至 50,000 美元以上** 起存，开户需提交公司注册证书、章程、董事及最终受益人（UBO）尽调文件或专业客户资质证明；
* **出入金通道**：仅支持**银行电汇（Bank Wire）**、内部账户划转以及**券商间资金划转（Broker-to-Broker Transfer，分亚太区与非亚太区通道）**，**不支持中国银联、信用卡、Skrill 或 USDT 等零售支付方式**；
* **银行托管选项**：机构客户可按需申请在**麦格理银行（Macquarie Bank）**开设独立隔离托管账户，进一步降低对手方信用风险。

## 与同赛道机构级流动性商的横向微对比

在同样主打机构级流动性、FIX API 直连与英国 FCA 监管的赛道中，Advanced Markets 常与 LMAX、Swissquote 机构端和 Finalto 放在一起对比：

| 对比维度 | Advanced Markets | LMAX | Swissquote 机构端 | Finalto |
| :--- | :--- | :--- | :--- | :--- |
| **创立时间** | **2006年** | 2010年 | 1996年（瑞士上市银行） | 2008年（原 CFH Clearing） |
| **核心监管牌照** | **英国 FCA (777739) / 澳洲 ASIC** | 英国 FCA / 直布罗陀 GFSC | 瑞士 FINMA / 英国 FCA | 英国 FCA / 塞浦路斯 CySEC |
| **主经纪商 / 托管** | **UBS / 渣打 / 麦格理银行** | 交易所中央限价订单簿 (CLOB) | 瑞士持牌银行自有资产负债表 | 多家 Tier-1 银行 PB |
| **零售散户开户** | **不支持（纯 B2B 机构）** | LMAX Global 支持专业/部分零售 | 支持零售（1,000 美元起） | 仅限 B2B 机构 |
| **核心接入方式** | **FIX API / PrimeXM / Fortex / MT4/5** | FIX API / ITCH / MT4/5 | FIX API / MT4 / MT5 / CFXD | FIX API / ClearPro / MT4/5 |

* **Advanced Markets vs LMAX / Swissquote**：LMAX 胜在交易所级中央限价订单簿（CLOB）撮合透明度，Swissquote 胜在瑞士上市银行牌照且兼顾高净值个人开户；Advanced Markets 胜在 **UBS 与渣打双主经纪商背书**、**PrimeXM/Fortex/oneZero 全桥接生态** 以及灵活的 PoP 机构定制方案。

## 开户通提醒：机构准入与散户避坑指南

结合 Advanced Markets 官网条款与监管边界，开户通提醒交易员重点留意以下四点：

1. **普通个人散户无法直接开户**：
   * 英国 FCA 实体（`777739`）严格限定仅服务专业客户与合格对手方，官网 FAQ 亦明确不直接服务零售散户，个人小资金交易员应选择 **Pepperstone**、**IC Markets** 或 **LMAX** 等支持零售/专业开户的持牌平台；
2. **警惕冒用“Advanced Markets 流动性”的离岸黑平台**：
   * 不少无牌或离岸小平台喜欢在宣传中声称“接入 Advanced Markets 顶级流动性”，甚至直接冒名招揽散户（如曾被官方点名辟谣的 Cooper Markets），务必通过官方渠道核实合作关系；
3. **资金门槛与企业 KYC 要求高**：
   * 机构与 FIX API 账户通常需 20,000–50,000 美元以上起存，且仅支持银行电汇与券商间划转，不支持银联或信用卡；
4. **全英文服务环境**：
   * 官网、合同文件与伦敦机构支持团队（`+44 204 591 4168`）均以英文为主，无中文零售客服。
