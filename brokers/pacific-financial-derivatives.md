**Pacific Financial Derivatives（简称 PFD）** 创立于 1999 年，总部位于新西兰奥克兰市中心 Swanson Street，是新西兰本土历史最悠久的持牌金融衍生品经纪商之一。公司先后于 1999 年获新西兰证券委员会授权、2011 年获 FMA 期货交易商认证，并于 2015 年正式依据《2013 年金融市场行为法》取得 **新西兰金融市场管理局（FMA）衍生品发行商牌照（FSP 编号：`FSP28944`，公司编号 `#973842`）**。

对厌恶高佣金的职业与高频交易员而言，PFD 最大的杀手锏在于极低的手续费架构——**`PFDPro` 账户每边仅收 1 美元/手（双边合计仅 2 美元/手）**，且 `PFDTrader` 与 `PFDPro` 均 **不设最低入金门槛**；但其 **5,000 美元净值分层杠杆（1:300 降为 1:100）**、**100% 初始强平线** 以及不支持银联/USDT 的传统电汇卡费架构，也让它明显偏向欧美澳新本地及量化熟手。

## PFDTrader、PFDPro 与 PFDProPlus 账户实测：双边 2 美元佣金有多省？

依据 `pfd-nz.com` 官方规格与平台实时报价流（2026 年实测采样），PFD 主打三档美元 MT4 账户及面向穆斯林客户的免隔夜息账户，全部采用 **市场执行（Market Execution / NDD）** 且不限制新闻交易、剥头皮或 EA：

* **PFDTrader（0 佣金 · 无最低入金）**：主打零佣金浮动点差，官网实时报价显示 `EURUSD` 约 **0.7 点**、`USDJPY` 约 **0.8 点**、`GBPUSD` 约 **0.8 点**、`XAUUSD` 约 **1.88 点**（18.8 points）；
* **PFDPro（双边 2 美元/手 · 无最低入金）**：核心拳头账户，按 **每边 1 美元/标准手** 收取固定佣金（仅为行业常规 6–7 美元水平的不到三分之一），官网实时报价显示 `EURUSD` 约 **0.3 点**、`USDJPY` 约 **0.4 点**、`GBPUSD` 约 **0.5 点**、`XAUUSD` 约 **1.18 点**；
* **PFDProPlus（1,000 美元起 · 净额隔夜息）**：在 `PFDPro` 的原始点差与双边 2 美元佣金基础上，支持对未对冲汇总头寸执行 **净额隔夜利息计算（Net out swaps）**，杠杆上限固定为 **1:100**、强平线 **50%**；
* **净值分层杠杆与爆仓规则**：`PFDTrader` 与 `PFDPro` 账户净值 **≤ 5,000 美元** 时最高享 **1:300 杠杆**，但追保线 **150%**、**强平线高达 100%**；一旦账户净值超过 **5,000 美元**，杠杆自动降为 **1:100**，同时强平线放宽至 **50%**。

## 交易软件与量化接口：纯 MT4 生态与直通 FIX API 4.2

在交易终端配置上，PFD 显得非常克制而硬核——至今仍以 **MetaTrader 4（MT4）** 作为唯一面向散户的交易终端（含 Windows、macOS、iOS、Android 与华为 AppGallery 适配版，**暂无 MT5 或 cTrader**），但为专业资金管理人与程序化交易员补充了机构级通道：

* **MT4 MultiTerminal（多账户终端）与 MAM**：支持多账户一键批量分仓与基金经理净值/手数分配；
* **FIX API 4.2 协议直连**：通过 `fixspec` 接口向机构与高频开发者开放核心聚合引擎与直通报价流（Direct access to core aggregation engine），且与 MAM 账户体系兼容。

## 监管与资金安全：NZ FMA (`FSP28944`)、ANZ/BNZ 信托专户与仿冒警示

核查新西兰政府公开注册簿及 `pfd-nz.com` 与 `pfd-fx.com` 双站信息，投资者必须清楚区分以下三组关键主体：

* **新西兰持牌主体（`pfd-nz.com`）**：即 **`Pacific Financial Derivatives Limited`**（新西兰公司编号 `#973842`，FMA 牌照号 **`FSP28944`**，官方监管页面可直接在 [新西兰 FMA 持牌名录](https://www.fma.govt.nz/compliance/licensed-providers/pacific-financial-derivatives-limited/) 核验），同时为 **新西兰金融纠纷解决机制（FDR）** 成员。依据《2014 年金融市场行为条例》，客户资金独立存放在 **澳新银行新西兰（ANZ Bank New Zealand，SWIFT: `ANZBNZ22`）** 与 **新西兰银行（BNZ，SWIFT: `BKNZNZ22`）** 的指定信托专户中，实行**每日对账**并在财年结束 4 个月内出具独立审计保证报告；
* **圣文森特离岸关联实体（`pfd-fx.com`）**：名为 **`Pacific Financial Derivatives LLC`**（注册于圣文森特和格林纳丁斯 Kingstown），同样提供 1:300 MT4 账户，但 **不受新西兰 FMA 监管**，电汇经由马来西亚纳闽 `Baroque Investment Bank` 账户，且明确规定 **无论入金还是出金均收取 2% 手续费**；
* **⚠️ 官方与 FMA 联合仿冒警告（`pfdmarkets.com`）**：新西兰 FMA 与 PFD 官网已于 2024 年 10 月末发布正式诈骗警示——**`pfdmarkets.com` 与 `app.pfdmarkets.com`（PFD Markets）系盗用 PFD 商标与注册号的假冒克隆平台**，与新西兰持牌实体没有任何关联，切勿向该域名汇款。

## 出入金实测：ANZ/BNZ 电汇、卡/PayPal 费率与纸质/在线提款

早期资料常将 PFD 误标为支持“银联/电汇”，实测 `pfd-nz.com/deposit` 与 `withdrawal` 页面后确认：**FMA 新西兰主体目前并不提供银联人民币或 USDT 通道**，仅支持传统银行电汇与主流卡/电子钱包：

* **ANZ / BNZ 多币种银行电汇**：支持 **USD、NZD、GBP、AUD、EUR、JPY** 六大币种直接汇入新西兰信托银行账户（`PFD` 不收电汇入金费，但国际电汇须自理中转行与汇出行费）；
* **Stripe 信用卡/借记卡**：新西兰本土卡费率 **2.65% + 0.30 纽元**，**国际银行卡费率高达 3.70% + 0.30 纽元**；出金原则上原卡退回不超过本金部分，超额盈利须经电汇或 PayPal 提现；
* **PayPal（最低 2 美元）**：新西兰本土入金收 **3.4% + 固定费**，**国际账户入金收 4.4% + 固定费（美元固定 0.30 美元）**，**PayPal 出金统一加收 2% 手续费**；
* **POLi 网银（新西兰本地）**：手续费 **1%**（封顶 3 纽元 + GST）；
* **出金流程**：支持后台 **Online Request**（凭 MT4 账号认证提交）或填报扫描 **Paper Mode 纸质出金表** 发送至 `backoffice@pfd-nz.com`。

## 开户通提醒：实盘客观痛点与开户前核验清单

虽然 PFD 具备罕见的 **新西兰 FMA 全牌照 + 双边 2 美元极低佣金** 组合，但结合实盘细节，交易员开户前仍有四项关键局限需要留意：

1. **5,000 美元以上资金杠杆骤降至 1:100，小额账户强平线达 100%**：
   * 在 `PFDTrader` 与 `PFDPro` 上，净值超过 **5,000 美元** 后杠杆立刻从 **1:300** 收紧到 **1:100**；而净值 ≤ 5,000 美元虽有 1:300 杠杆，**100% 的强平线** 意味着抗回撤空间只有主流 20%–50% 强平平台的几分之一，重仓短线极易触发强平；
2. **亚洲客户出入金成本高且缺少银联/加密通道**：
   * 跨国用户若用国际 Visa/Mastercard（3.70%）或 PayPal（入金 4.4%、出金 2%）划转，通道损耗远高于行业平均水平；大资金建议直接通过合规境外同名银行电汇至其 ANZ/BNZ 信托户；
3. **分清 `pfd-nz.com` 与 `pfd-fx.com`，远离 `pfdmarkets.com`**：
   * `pfd-nz.com` 才是受新西兰 FMA 监管且资金存放在 ANZ/BNZ 的本体；`pfd-fx.com` 属于圣文森特离岸主体且充提各收 2% 费用；而 **`pfdmarkets.com` 已被官方与 FMA 实锤为诈骗克隆站**；
4. **纯 MT4 架构与有限的品种深度**：
   * 无 MT5、无美股单只股票 CFD 也没有全天候加密货币交易对（且受限于美国禁止开户条款），更适合专攻外汇、黄金和指数、且手握 MT4 EA 的低点差低佣金策略交易者。

<div id="faq-question-1" class="rank-math-list-item">
<h3 class="rank-math-question ">Pacific Financial Derivatives (PFD) 是正规受监管的券商吗？</h3>
<div class="rank-math-answer "><p>是的。Pacific Financial Derivatives Limited 于 1999 年成立于新西兰奥克兰（公司编号 #973842），持有新西兰金融市场管理局（FMA）颁发的衍生品发行商牌照，FSP 注册号为 FSP28944，同时也是新西兰金融纠纷解决机制（FDR）成员，客户资金独立托管在 ANZ 澳新银行和 BNZ 新西兰银行信托账户内。</p></div>
</div>
<div id="faq-question-2" class="rank-math-list-item">
<h3 class="rank-math-question ">PFD 的主要官网是什么？pfd-fx.com 和 pfdmarkets.com 有什么区别？</h3>
<div class="rank-math-answer "><p>新西兰 FMA 持牌主体的唯一官网是 pfd-nz.com；pfd-fx.com 为其圣文森特和格林纳丁斯离岸关联实体（Pacific Financial Derivatives LLC），不受 FMA 监管且出入金各收 2% 费用；而 pfdmarkets.com（及 app.pfdmarkets.com）已被新西兰 FMA 与 PFD 官方公告定性为盗用商标的诈骗仿冒网站，切勿访问或入金。</p></div>
</div>
<div id="faq-question-3" class="rank-math-list-item">
<h3 class="rank-math-question ">PFD 的交易佣金和点差水平如何？有最低入金要求吗？</h3>
<div class="rank-math-answer "><p>PFDTrader（0 佣金）与 PFDPro（每边 1 美元/手、双边仅 2 美元/手）均不设最低入金门槛；PFDProPlus 最低入金 1,000 美元，同样享受双边 2 美元/手超低佣金及净额隔夜息计算。官网实时报价显示 PFDPro 欧美点差约 0.3 点、黄金约 1.18 点。</p></div>
</div>
<div id="faq-question-4" class="rank-math-list-item">
<h3 class="rank-math-question ">PFD 的最高杠杆和强平（爆仓）比例是多少？</h3>
<div class="rank-math-answer "><p>在 PFDTrader 与 PFDPro 账户上，账户净值在 5,000 美元及以下时最高杠杆为 1:300，追保线 150%、强平线 100%；若净值超过 5,000 美元，杠杆降至 1:100，强平线放宽至 50%。PFDProPlus 账户杠杆固定 1:100，强平线为 50%。</p></div>
</div>
<div id="faq-question-5" class="rank-math-list-item">
<h3 class="rank-math-question ">PFD 支持银联、支付宝或 USDT 出入金吗？手续费贵吗？</h3>
<div class="rank-math-answer "><p>新西兰主体 pfd-nz.com 不支持银联人民币或 USDT，仅支持新西兰 ANZ/BNZ 银行电汇、Stripe 银行卡、PayPal 与新西兰本地 POLi。国际信用卡入金费率 3.70%+0.30 纽元，PayPal 国际入金 4.4%+固定费且出金收 2%，电汇则由客户自理银行中转费。</p></div>
</div>
<div id="faq-question-6" class="rank-math-list-item">
<h3 class="rank-math-question ">PFD 支持 MT5 或 FIX API 吗？</h3>
<div class="rank-math-answer "><p>PFD 全系散户及资管账户目前仅提供 MetaTrader 4（MT4）、MT4 MultiTerminal 与 MAM，尚未上线 MT5；但同时向机构与程序化交易员开放 FIX API 4.2 接口直连。</p></div>
</div>
